Data Quality Review — Findings Summary

Course and Award Data Quality in the CRICOS Register

A review of the University of Sydney’s course and award records

Prepared by
Reggie Alderson
Purpose
Supporting document, Data Analyst (Academic Model) application
Date
September 2026
Data source
CRICOS national register (data.gov.au); 655 University of Sydney records

I reviewed the University of Sydney’s 655 course and award records in the CRICOS register — the official public list of courses. Most of the data is in good shape: every record was complete, every course code was unique, and every qualification level was valid. The review did find a small number of clear issues worth correcting, listed below in order of priority.

Detail

1. Spelling mistakes in course names High priority

Five course names contain a spelling mistake. These are official names that appear on student records and graduation documents, so they are worth fixing promptly. I found them by comparing each word against all ~26,000 course names in the national register — a genuine misspelling stands out clearly.

  • Bachelor of Information Techonology (Honours) → should be Technology
  • Doctor of Philsophy in Engineering → should be Philosophy (two records)
  • Grauate Diploma in Design Science → should be Graduate
  • Graduate Certificate in Engineeering → should be Engineering

2. Courses listed more than once Medium priority

In 45 cases the same course, at the same level, is listed under more than one active code. Where a course has more than one live listing, it is worth confirming which one is current and retiring the rest, so the records stay consistent and are not counted twice.

  • Graduate Diploma in Computing — listed 3 times
  • Master of Data Science — listed twice
  • Bachelor of Psychology — listed twice, with 42 further examples

3. Formatting inconsistencies in course names Low priority

Small, cosmetic issues in how names are written. Minor, but they look untidy on published material and can cause the same course to be missed when records are matched by name.

  • A double space in the name — e.g. Graduate  Certificate in Health Communication
  • A stray space inside brackets — e.g. … Arts ( Cotutelle)
  • Seven names use “&” where the rest of the register uses “and”

Method

I downloaded the national CRICOS register as a single public file from data.gov.au and pulled out the University of Sydney’s 655 records. I then ran a set of automated checks, each of which lists only the records that fail it. The process is repeatable, and the underlying code is available.

Recommendations

  1. Correct the spelling mistakes and spacing now — they are quick to fix and affect names that students see.
  2. Review the 45 courses listed more than once and retire any listings that are out of date.
  3. Run these checks regularly — for example, each time the data is updated — so new issues are caught early.
