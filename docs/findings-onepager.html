Data Quality Review — Findings Summary

Course and Award Data Quality in the CRICOS Register

A review of the University of Sydney’s course and award records

Prepared by
Reggie Alderson
Purpose
Supporting document, Data Analyst (Academic Model) application
Date
September 2026
Data source
CRICOS national register (data.gov.au); 655 University of Sydney records

I reviewed the University of Sydney’s 655 course and award records in the CRICOS register — the official public list of courses. Most of the data is in good shape: every record was complete, every course code was unique, and every qualification level was valid. The review did find a small number of clear issues worth correcting, listed below in order of priority.

Detail

1. Spelling mistakes in course names High priority

Five course names are misspelled. Because these names appear on student records and graduation documents, they are worth correcting promptly.

  • Bachelor of Information Techonology (Honours) → Technology
  • Doctor of Philsophy in Engineering → Philosophy (two records)
  • Grauate Diploma in Design Science → Graduate
  • Graduate Certificate in Engineeering → Engineering

2. Courses listed more than once Medium priority

In 45 cases the same course, at the same level, is listed under more than one active code. Each should be confirmed and any out-of-date listing retired, so records stay consistent and are not counted twice.

  • Graduate Diploma in Computing — listed 3 times
  • Master of Data Science — listed twice
  • Bachelor of Psychology — listed twice, with 42 further examples

3. Formatting inconsistencies in course names Low priority

Small, cosmetic issues in how names are written — untidy on published material, and enough to make the same course be missed when records are matched by name.

  • A double space — e.g. Graduate  Certificate in Health Communication
  • A stray space inside brackets — e.g. … Arts ( Cotutelle)
  • Seven names use “&” where the rest of the register uses “and”

Method

I downloaded the national CRICOS register as a single public file from data.gov.au, extracted the University of Sydney’s 655 records, and ran a set of automated checks that each list only the records that fail. The process is repeatable and the code is available.

Recommendations

  1. Correct the spelling and spacing now — quick to fix, and they affect names students see.
  2. Review the 45 courses listed more than once and retire any out-of-date listings.
  3. Run these checks each time the data is updated, so new issues are caught early.
